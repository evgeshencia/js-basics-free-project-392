
Генератор и анализатор паролей

Простая и эффективная утилита на JavaScript (Node.js), которая позволяет безопасно генерировать псевдослучайные пароли на основе алгоритма линейного конгруэнтного генератора и оценивать их уровень надежности. Проект выполнен в рамках обучения на платформе Hexlet.

Функционал

1. Генерация паролей (generatePassword):
	• Создание пароля заданной длины.
	• Настройка состава символов через опции (включение/выключение цифр, прописных букв и специальных символов !@#$%^&*).
	• Воспроизводимость результатов благодаря использованию числового сида (seed).
2. Проверка надежности (checkPassword):
	• Анализ пароля по 5 критериям (длина от 8 символов, наличие строчных, прописных букв, цифр и спецсимволов).
	• Вывод текстового вердикта: Слабый, Средний, Надёжный или Очень надёжный.

Запуск приложения

Для того чтобы проверить работу генератора и анализатора совместно, запустите исполняемый файл проекта через терминал:
bash
node main.js


Пример вывода программы

При запуске node main.js приложение сгенерирует тестовые пароли и сразу проверит их надежность. Вывод в консоли будет выглядеть следующим образом:
text
abcde1234 -> Средний
Abcdef123! -> Очень надёжный
